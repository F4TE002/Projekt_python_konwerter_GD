ŹRÓDŁA, BIBLIOTEKI I NARZĘDZIA
=============================


BIBLIOTEKI PYTHONA
------------------

Biblioteka standardowa (nie wymaga instalacji):
- csv          - odczyt i zapis plików CSV
- json         - odczyt i zapis plików JSON
- subprocess   - uruchamianie LibreOffice
- shutil       - wyszukiwanie programu w PATH (shutil.which)
- os, sys      - zmienne środowiskowe i rozpoznanie systemu operacyjnego
- pathlib      - operacje na ścieżkach
- dataclasses  - klasa ConversionRequest
- time         - pomiar czasu konwersji
- tkinter/ttk  - interfejs graficzny
- threading    - konwersja w osobnym wątku (okno nie zamarza)
- queue        - przekazanie wyniku z wątku roboczego do okna
- unittest, unittest.mock, tempfile - testy automatyczne

Biblioteka zewnętrzna (instalowana przez pip):
- pypdf        - odczyt tekstu z plików PDF


NARZĘDZIA
---------

- LibreOffice (tryb --headless) - konwersje DOCX, ODT, PDF i TXT
- Visual Studio Code            - edytor kodu
- Git / GitHub Desktop          - kontrola wersji
